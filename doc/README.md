# 專案文件管理庫 (doc/)

本目錄存放「**專案管理與 RFI 追蹤系統**」之所有技術計畫與正式系統規格。

---

## 結構與職責說明

```
doc/
├── dev/                    # 🚀 功能開發計畫存放區
│   ├── README.md           # dev 開發流程說明
│   └── template_plan.md    # 計畫撰寫範本 (plan_<功能名稱>.md)
└── spec/                   # 📖 正式系統規格庫 (分章節撰寫)
    ├── README.md           # 規格目錄與導引
    ├── 01_系統總覽與架構.md
    ├── 02_敏捷看板與任務管理.md
    ├── 03_工程RFI資訊需求單.md
    ├── 04_甘特圖時程與排程.md
    ├── 05_即時HTML工作室與附件管理.md
    └── 06_角色權限控制與稽核日誌.md
```

---

## 核心協同開發生命週期

1. **開發前**：
   - 討論並釐清需求。
   - 於 `doc/dev/` 建立 `plan_<功能名稱>.md`。
   - 參照計畫進行逐項實作。
2. **開發完成後**：
   - 通過測試與驗證。
   - 將正式規格寫回 `doc/spec/` 對應的章節文件中，保持文件與實作同步一致。
