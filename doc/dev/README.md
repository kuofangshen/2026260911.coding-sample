# 功能開發計畫區 (doc/dev/)

本目錄用於存放所有**新功能開發或重大重構之事前討論計畫**。

---

## 規範與命名原則

1. **討論先行**：
   - 任何功能實作前，AI 代理與工程師必須先進行需求與架構討論。
2. **檔案命名原則**：
   - 檔名必須嚴格使用：`plan_<功能名稱>.md`
   - 例如：
     - `plan_看板自訂欄位排序.md`
     - `plan_rfi匯出pdf與列印.md`
     - `plan_甘特圖相依關聯線.md`
3. **持續參照與勾稽**：
   - 開發過程需對照該計畫逐步完成。
4. **開發完成後**：
   - 功能驗證完成後，必須將最終規格寫回 [`doc/spec/`](file:///c:/%E6%96%B0%E5%A2%9E%E8%B3%87%E6%96%99%E5%A4%BE%20%282%29/2026260911.coding-sample/doc/spec/) 對應章節，並在計畫中標註狀態為已完成。

---

## 快速開始

請複製 [`template_plan.md`](file:///c:/%E6%96%B0%E5%A2%9E%E8%B3%87%E6%96%99%E5%A4%BE%20%282%29/2026260911.coding-sample/doc/dev/template_plan.md) 建立新的計畫檔案。
