# 第五章：即時 HTML 工作室與附件管理模組規格

## 1. 模組目標
支援團隊在進行介面原型、報告呈現、工程互動圖表或 HTML 交付物時，提供即時編寫預覽環境；並提供跨任務與 RFI 之通用檔案/圖片附件管理。

## 2. 即時 HTML 工作室 (LiveHtmlEditor) 規格
1. **雙欄編輯與即時預覽**：
   - 左側（或頂部）為程式碼輸入區，右側（或底部）為安全沙盒渲染區。
   - 支援全螢幕切換與範本快速載入（如工程統計卡片、驗收表格範本）。
2. **沙盒隔離 (Security Sandbox)**：
   - 預覽區塊採用 `<iframe>` 容器，屬性嚴格限制為：
     ```html
     <iframe sandbox="allow-scripts" srcDoc={htmlContent} />
     ```
   - 阻擋任何向父層視窗存取之跨域腳本，避免 XSS 漏洞。
3. **回存與任務關聯**：
   - 編輯完成後，可指定目標看板卡片，將 HTML 代碼一鍵回存至 `Card.htmlSnippet`。
   - 在 `CardModal` 中可直接開啟小型內嵌預覽。

## 3. 剪貼簿與附件管理 (Attachment) 規格
1. **剪貼簿貼圖支援**：
   - 在卡片編輯視窗或 RFI 回覆視窗中按下 `Ctrl + V`，自動偵測剪貼簿中的圖像資料（`image/png`, `image/jpeg`）。
   - 自動將其轉換為 Base64 或物件 URL，並生成附件記錄加入清單。
2. **檔案型別支援**：
   - `image`: 支援縮圖與放大燈箱預覽。
   - `pdf`: 支援內嵌 PDF Viewer 或在新分頁瀏覽。
   - `code` / `doc`: 支援原始碼檢視與文字預覽。
3. **全螢幕燈箱 (FilePreviewModal)**：
   - 點擊任一附件即可喚起燈箱視窗，提供旋轉、縮放與原始檔下載按鈕。
