# 第四章：甘特圖時程與排程管理模組規格

## 1. 模組目標
將所有具備時程屬性之任務卡片轉換為甘特圖（Gantt Chart）時間軸檢視，清晰掌握工程各階段進度、到期風險與瓶頸。

## 2. 顯示與排程計算規格

### 2.1 階段分組 (Phase Grouping)
- 任務依據 `Card.phase` 進行分組（例如：「前置準備」、「工單管理」、「現場施作」、「驗收交付」）。
- 支援階段展開/收合互動。

### 2.2 時間軸座標與長度計算
- **時間跨度**：以天 (Day) 為基礎單位，起始日為全部卡片最早之 `startDate`，結束日為最晚之 `dueDate`。
- **卡片長度與位置**：
  - `offset = (startDate - timelineStart) / totalDays`
  - `width = (dueDate - startDate) / totalDays`
- **今日標線 (Today Marker)**：時間軸上以亮色垂直虛線或標記醒目標註當前日期。

### 2.3 進度百分比計算 (Progress %)
- 若任務具備 `checklist`：
  - `進度 = (已勾選項目數 / 總項目數) * 100%`
- 若任務無 `checklist`：
  - 若位於最後完成欄位（如「已完成」），則進度為 100%；否則依所在欄位預設進度估計。

### 2.4 風險警示 (Overdue Alert)
- 當任務截止日早於今日，且任務尚未移動至「已完成」欄位時，以紅色警示圖示與外框高亮顯示為「逾期」。
