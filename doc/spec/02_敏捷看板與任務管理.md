# 第二章：敏捷看板與任務管理模組規格

## 1. 模組目標
提供團隊視覺化的任務流動管理，支援多欄位自訂、WIP 數量管制、優先級標示、細部查核清單與雙向關聯 RFI。

## 2. 資料結構規格

### 2.1 欄位 (Column)
- `id` (string): 欄位唯一識別碼（如 `col-backlog`, `col-progress`）
- `boardId` (string): 所屬看板識別碼
- `title` (string): 欄位顯示名稱
- `orderIndex` (number): 排序索引
- `color` (string, optional): 頂部裝飾條或標籤色
- `maxCards` (number, optional): WIP 限制上限，超過時欄位發出視覺警示

### 2.2 任務卡片 (Card)
- `id` (string): 卡片唯一編號（格式：`card-<uuid>`）
- `boardId` (string): 所屬看板
- `columnId` (string): 當前所在欄位
- `title` (string): 任務主標題
- `description` (string): 任務內容詳情
- `priority` (enum: `'low' | 'medium' | 'high' | 'urgent'`): 優先度
- `startDate` (string, ISO YYYY-MM-DD): 起始日
- `dueDate` (string, ISO YYYY-MM-DD): 截止日
- `phase` (string, optional): 工程階段分類（如「前期設計」、「工單管理」）
- `tags` (string[]): 標籤清單
- `assignees` (string[]): 指派之成員 User ID 清單
- `rfiId` (string, optional): 雙向綁定之 RFI ID
- `checklist` (ChecklistItem[]): 查核清單，每項包含 `id`, `text`, `completed`
- `htmlSnippet` (string, optional): 內嵌 HTML 成果程式碼
- `attachments` (Attachment[]): 關聯之附件清單

## 3. 功能操作規格
1. **卡片拖曳與欄位切換**：
   - 拖曳卡片時即時更新 `columnId` 與 `updatedAt`。
   - 記錄操作至稽核日誌 (`ActivityLog`)。
2. **卡片新增與編輯**：
   - 支援點擊欄位頂部「+」快速於特定欄位建立卡片。
   - 點擊卡片開啟 `CardModal`，支援即時編輯標題、描述、檢查項目、指派負責人、設定標籤與優先級。
3. **查核清單 (Checklist)**：
   - 即時計算完成進度（如 `2/5 項完成`），並反映在甘特圖進度百分比上。
4. **WIP 限制 (Work in Progress Limit)**：
   - 當欄位卡片數量超過 `maxCards`，欄位頂部計數顯示紅色警告色。
