## 規格維護原則

1. **章節式組織**：
   - 每個核心模組或系統切分為獨立章節檔案。
   - 新增跨領域大型功能時，應擴充對應章節或新增 `07_xxx.md`。
2. **回寫時機**：
   - 任何 `doc/dev/plan_<功能名稱>.md` 於開發與驗證完畢後，即時在此更新。
3. **規格內文規範**：
   - 包含：功能目標、資料欄位定義、操作流程、權限約束與錯誤處理。
