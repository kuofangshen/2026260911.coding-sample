# 第一章：系統總覽與技術架構規格

## 1. 系統目標
「專案管理與 RFI 追蹤系統」旨在為現代工程與敏捷團隊提供一站式協同作業平臺，整合看板、工程疑義單 (RFI)、甘特圖排程、即時 HTML 成果預覽與細緻的角色權限控制。

## 2. 技術環境與相依套件
- **執行環境**：Node.js >= 18, ESM 模組系統
- **前端核心**：React 19, TypeScript ~5.8, Vite 6
- **樣式庫**：Tailwind CSS v4 (`@tailwindcss/vite`)
- **圖示庫**：`lucide-react`
- **動畫庫**：`motion`
- **圖表庫**：`recharts`
- **後端伺服器**：`express` 4.21, `dotenv`

## 3. 系統啟動與佈署規格
1. **開發環境啟動**：
   - 執行指令：`npm run dev` 或點擊專案根目錄之 `start-server.bat`
   - 預設開發埠號：`5173` (Vite 預設) 或動態分配。
2. **生產環境託管**：
   - 先行建置：`npm run build`
   - 啟動 Express 本機伺服器：`node server.js`
   - 伺服器監聽預設 Port：`3000` (可透過環境變數 `PORT` 覆蓋)
   - 提供 `/api/health` 供系統狀態探測，並自動將非 API 流量路由至 `dist/index.html`。
3. **安全結束管理**：
   - 伺服器啟動時於專案目錄建立 `.server.pid`。
   - 透過 `關閉伺服器.bat` 讀取 PID 執行安全終止並刪除 PID 標記檔。
